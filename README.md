# VisionGuard

VisionGuard is an AI-powered smart surveillance and security management system using YOLOv8, OpenCV, ByteTrack and Flask.

## Features

- Real-time laptop webcam monitoring
- YOLOv8 object detection
- Person detection
- ByteTrack object tracking
- People counting
- Restricted-zone detection
- Entry and exit line crossing
- Loitering detection
- Risk scoring
- Security incident generation
- Incident evidence screenshots
- Real-time FPS monitoring
- AI inference-time monitoring
- Web-based security dashboard
- Incident history and reports

## Technology Stack

- Python
- Flask
- OpenCV
- YOLOv8
- Ultralytics
- ByteTrack
- HTML
- CSS
- JavaScript
